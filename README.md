# Human-Centered AI Workshop Assets

This repository contains an end-to-end Jupyter Notebook and supporting deliverables for a Human-Centered AI hands-on session.

## Contents
- `HCAI_end_to_end_workshop.ipynb`: Full workflow with methodology, code templates, and analysis guidance.
- `deliverables/`: Pre-built static prototypes, dummy survey data, logs, and qualitative annotations.

## Quick Start
1. Open the notebook and run the **Environment Setup** cell if needed.
2. Review the project definition and research methodology sections.
3. Use the dummy CSV files in `deliverables/data/` to move between steps during class.
4. Serve the static prototypes:
   ```bash
   cd deliverables/project1_app
   python -m http.server
   ```

## Notes
- The notebook includes instructions for using Gemini (prefer Gemini 3 Flash Lite if available) and AutoGluon.
- All dummy data is synthesized for educational use.
